# ToolHub v0.3.0-beta.6 — 分层工作台与设计台 / Layered workbench & Design Studio

## 更新

- **两级导航**：一级按工作区分类，二级显示当前功能；扩展增多时导航仍可定位，支持收藏及紧凑视图。
- **设计台 0.2.0**：12 个精选视觉方向、10 类布局、封面与字体语言、展开动画、无限画布与实际视口裁剪。Android / Web / 桌面切换会改变外壳与内容重排；实时预览同步输出 JSON、可运行 HTML 和 Agent 设计说明。
- **可复用预设**：设计草稿与最多 24 个自定义预设独立保存到包专属存储，支持备份导入；第三方页面不获得数据库或执行权限。
- **MCP 行为声明**：16 个通用工具全部返回 readOnlyHint、destructiveHint、idempotentHint、openWorldHint。完整调用包含本地活动时间记录，采用保守标注；执行、取消和可能触发后续回收的操作明确说明副作用。提示不授予权限。
- **协议验证**：真实隔离 daemon 调用覆盖全部 16 个工具，检查未收录程序不会执行、默认高优先级产物保留、回收保护、无效实例/任务/授权请求拒绝及结果/错误格式。
- **分仓发布**：主程序安装包位于本仓库；设计台独立包、源码及校验值位于 [ToolHub-Extensions](https://github.com/xiyuxiao1314/ToolHub-Extensions/releases/tag/design-studio-v0.2.0)。已有 FFmpeg 等扩展继续兼容。

## 下载与升级

Windows x64：`ToolHub-v0.3.0-beta.6-windows-x64.zip`。macOS 13+：按芯片选择 `macos-arm64` 或 `macos-x64` 的 DMG/ZIP。仅 MCP/CLI 使用 `ToolHub-CLI-v0.3.0-beta.6-<平台>.zip`；核对 SHA256SUMS.txt。Windows 解压后可先运行 `install-local.ps1 -VerifyOnly`，再运行安装脚本；保留用户目录 `.toolhub`。不要用新目录覆盖运行中的旧二进制。

设计台是可选扩展：在“扩展”中导入并核对独立包；需要 beta.6 的预设存储接口。主程序 ZIP 附兼容示例，独立更新以扩展仓库为准。升级不会主动删除工具、程序、产物或预设。

Windows 二进制未签名。macOS 使用 ad-hoc 签名、未公证；原生 CI 构建/测试通过才发布，不表示实体 Mac 交互已验收。macOS 受控执行/审批仍不可用，不降级绕过身份校验。无限画布是 DOM 相机及裁剪，并非通用图形编辑器；设计示例为原创代码与插画，不包含参考网站资源。M8ven 认领、重扫及评分不构成本版本的运行依赖或安全认证。

## English

This prerelease adds a two-level workbench navigation and Design Studio 0.2.0: twelve visual directions, ten layout families, distinct Web/Android/desktop previews, cover/type choices, expansion/motion, camera-based canvases and actual viewport culling. Export matching JSON, runnable HTML and Agent instructions; keep up to 24 reusable local presets with bounded per-package storage.

All sixteen MCP meta-tools now return the four explicit boolean behavior hints. Successful calls persist client activity, so query calls are conservatively not strictly read-only/idempotent. Arbitrary execution is open-world/destructive; cancellation and deferred artifact recycling are marked destructive. Hints never grant trust or bypass existing policy. Isolated process conformance covers every tool, pending proposals, default-high retained artifacts, protected review rejection and missing-ID execution/approval/task denial.

Host packages are released here; independent Design Studio source/packages/checksums are released in [ToolHub-Extensions](https://github.com/xiyuxiao1314/ToolHub-Extensions/releases/tag/design-studio-v0.2.0). Download Windows x64 ZIP or the matching macOS 13+ ARM64/Intel DMG/ZIP, or CLI-only ZIP, then verify SHA256SUMS.txt. Windows binaries remain unsigned; macOS is ad-hoc signed, not notarized. Native CI results do not establish physical Mac interactive parity; controlled execution/approval remains unavailable on macOS. Existing user data and presets are retained. No FFmpeg/Electron binary is bundled or downloaded.
