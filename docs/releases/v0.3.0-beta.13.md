# ToolHub v0.3.0-beta.13 — 服务监控与 Skill 分发 / Services & Skill distribution

## 更新

- **服务监控扩展**：观察 ToolHub 启动或 Agent 主动登记的服务，显示应用图标、真实进程、子进程与端口；关联程序入口，支持手动停止、重启和明确设置运行时限。默认 30 秒刷新，可选 5 秒、1 分钟、2 分钟或手动；页面隐藏时暂停界面轮询。
- **稳定服务身份**：同一程序重复启动复用当前实例；重启保留卡片、页面地址和历史。可明确配置独立托盘的执行文件与参数观察规则，缺失或歧义时不猜测；陈旧 PID 操作被拒绝。保存 HTTP/HTTPS 地址后可用默认浏览器打开，进程运行不等于网页就绪。
- **代理只读观察**：显示已配置的代理端口、Windows 当前用户系统代理与 PAC 状态；不停止代理、不改动代理软件或系统设置。端口监听不代表网络连通。
- **Skill 收录与分发**：先在原宿主安装，再可选收录完整 Skill 目录；由用户选择目标宿主，保留版本、摘要与逐目标历史。阻止覆盖目标本地修改，宿主专属 Skill 不跨宿主下发；文件同步与实际加载分开显示。Agent 提交待同步后继续原任务，不自动操作桌面或等待。
- **工具识别与选择**：Windows 系统 cURL 使用原生签名和内容绑定核验；能力解析保留明确路径与项目偏好，再选择满足约束的最新稳定候选。版本较新不等于安全，未知/阻止状态及执行策略继续生效。
- **扩展照片存储**：提供有边界、按包隔离的照片导入/移除接口，供独立画廊扩展使用；不向扩展开放任意文件访问。第三方扩展仍在独立仓库分发。
- **Agent 接口**：19 个固定 MCP 元工具，新增 `offer_skill_sync`、`register_service`、`list_services`，按需返回元数据，不为每个应用生成新工具。

## 下载与升级

Windows x64 下载 `ToolHub-v0.3.0-beta.13-windows-x64.zip`；macOS 13+ 按芯片选择 ARM64 / Intel DMG 或 ZIP。只需 MCP/CLI 可下载 `ToolHub-CLI-v0.3.0-beta.13-<平台>.zip`。使用 `SHA256SUMS.txt` 核对文件。

Windows 解压后用 PowerShell 7 运行 `./install-local.ps1 -VerifyOnly` 核对，再运行 `./install-local.ps1`。当前用户数据保留；不要覆盖运行中的旧二进制。已有 Agent 的 MCP 路径指向旧目录时，需要在对应宿主中更新路径并重新连接；安装不会自动修改所有宿主。保留程序入口、工具信任、Skill 和扩展数据，不捆绑 FFmpeg、Python 或 Electron。

Windows 二进制未签名；macOS 为 ad-hoc 签名、未公证。服务监控、系统签名信任和受控执行是 Windows 功能，其他平台明确返回不可用。macOS 只在原生 CI 构建、测试与包校验通过后发布，不代表实体 Mac 交互验收。独立托盘观察不证明项目归属，也不授予信任、自动停止或任意进程控制权限。ToolHub 不自动为本地域名添加代理例外。

## English

This release adds an optional Windows Service Monitor for ToolHub-launched or explicitly registered applications: app identity/icons, process trees, ports, linked program entries, manual stop/restart and opt-in runtime limits. Refresh every 5/30/60/120 seconds or manually; hidden pages pause UI polling. Stable cards survive PID changes and retain their URLs/history. Duplicate launch requests reuse an existing instance. Explicit bounded executable/argument selectors can observe detached trays; missing/ambiguous matches and stale stop requests are rejected rather than guessed. Process liveness does not establish web readiness.

Proxy observation remains read-only. Saved HTTP/HTTPS service URLs open in the default browser only on user action; ToolHub does not change proxy exceptions. Skill collection/distribution preserves full folders, source revisions, per-host digests and history, detects local conflicts, and separates file delivery from unknown host load status. Host-specific Skills remain scoped to their host. Agents offer optional sync metadata and continue without operating the desktop or waiting.

Windows system cURL recognition now uses native signature/content evidence. Resolution respects explicit/project preferences before choosing the newest stable eligible candidate; version numbers never grant trust. Bounded package-owned photo storage supports independently installed gallery extensions. MCP now exposes nineteen fixed meta-tools, including `offer_skill_sync`, `register_service` and `list_services`.

Download the matching Windows x64 ZIP or macOS 13+ ARM64/Intel DMG/ZIP, or the CLI-only ZIP, then verify SHA256SUMS.txt. User data is retained. Reconnect MCP clients if their executable path changes. Windows binaries remain unsigned; macOS packages are ad-hoc signed and not notarized. Native CI success does not establish physical Mac interactive parity. Service monitoring, native system trust and controlled execution remain Windows-only. Discovered third-party software is not bundled.
