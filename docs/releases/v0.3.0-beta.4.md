# ToolHub v0.3.0-beta.4 — Declarative CLI extensions (unreleased)

- First installable FFmpeg media panel: video compression, MP4 conversion, M4A extraction using an existing local tool. Native file/choice form, exact argv preview, one-run authorization, background tasks, cancel, final logs and output reveal.
- Additive v2 CLI declaration and controller-only THP preview/start; no arbitrary execution for iframe scripts. Package digest, tool definition, path/parameter checks and existing policy/trust/pinning remain mandatory.
- Portable Agent Skill reuses the existing sixteen MCP tools and compact discovery; no per-extension tool-definition expansion.
- Extension directory type/platform filters. Independent extension catalog prepared with bilingual docs, browse filters, manifests and SHA-256 checks.

Limits: Windows controlled execution only; macOS preview/query without native execution verification. Local FFmpeg may lack libx264/AAC. Five-minute task limit; no percent progress or live logs; cancelled/failed output retained. No dependency installer or embedded terminal. Public release is still beta.2; this local development build is not a published release.
