# ToolHub v0.3.0-beta.5 — 扩展工作台 / Extension workbench

这是 beta.2 之后的整合公开预览版，包含此前本地 beta.3、beta.4 和最新 beta.5 的改造。

## 主要更新

- **插件架构**：工具、程序、产物、环境、Skill、市场和任务拆为七个默认启用的官方扩展。支持安装、停用、卸载、编辑与回滚，卸载保留用户数据。Agent 接入、权限与界面恢复保留在核心。
- **自定义导航与界面**：独立扩展可以增加隔离 HTML/CSS/JavaScript 页面、导航入口、主题、侧栏/顶部布局和密度。第三方页面通过受限 SDK 调用查询接口，不能直接获取本机控制权限。
- **FFmpeg 媒体工坊**：首个声明式 CLI 扩展，支持视频压缩、MP4 转换和 M4A 音频提取。核心负责选择文件、预览准确参数、单次确认、后台任务及取消；不附带或下载 FFmpeg。
- **公开扩展目录**：[ToolHub-Extensions](https://github.com/xiyuxiao1314/ToolHub-Extensions) 提供类型/标签/平台筛选、扩展源码及 SHA-256 校验。安装仍需明确选择；Release 另附示例扩展集合。
- **Agent 上下文优化**：保留 16 个通用 MCP 工具；搜索默认仅返回 5 条摘要，完整实例和 Skill 正文按需加载，配置与高级说明拆分。
- **项目工具依赖发现**：从选定项目的 package.json、Electron 包信息及实际二进制定位依赖；支持多项目/多版本、共享路径去重、显式自定义分发目录和独立缺失状态，不遍历所有 node_modules。
- **Electron 版本与归属**：登记真实版本、路径和项目关联，Windows 可读取大型二进制的版本资源；发现不执行程序、不自动提升信任。缺失/无效二进制不伪装成可用实例。
- **存储维护**：提供预览优先的编译缓存和历史安装包维护，保护正在运行、被引用、当前及回退版本；历史包先进入回收站。

## 下载

| 用途 | 文件 |
| --- | --- |
| Windows 10/11 x64 桌面 | `ToolHub-v0.3.0-beta.5-windows-x64.zip` |
| macOS 13+ Apple Silicon | `ToolHub-v0.3.0-beta.5-macos-arm64.dmg` / `.zip` |
| macOS 13+ Intel | `ToolHub-v0.3.0-beta.5-macos-x64.dmg` / `.zip` |
| CLI / MCP（各平台） | `ToolHub-CLI-v0.3.0-beta.5-<platform>.zip` |
| 示例扩展与 SDK | `ToolHub-Extensions-v0.3.0-beta.5.zip` |
| 校验 | `SHA256SUMS.txt` |

Windows 解压后可直接打开桌面程序；持久安装可运行 `install-local.ps1 -VerifyOnly` 后运行 `install-local.ps1`，按需指定 `-UpdateCodexMcp`。所有二进制必须来自同一个包。升级前保留自己的数据库备份，已有 MCP 会话需要重连/重启宿主以加载新的配对 CLI/daemon。普通解压与安装不会收录你的私人程序或提升工具信任。

macOS 将 ToolHub.app 拖入 Applications，CLI 包保留其配对 daemon。Mac 应用仅作 ad-hoc 签名，未通过 Apple Developer 签名或公证；Windows 未作发布者签名。请从本仓库核对来源与 SHA-256，不需要关闭系统安全检查。

## 边界

Windows 受控工具执行和 FFmpeg 转码经过本机验证；macOS 提供原生构建包，但身份绑定执行/审批仍暂不可用，新交互能力仍需真实 Mac 验收。第三方插件不是任意原生后台代码运行器。Electron 当前仅针对明确选定的项目，不隐式解析所有工作区/父目录依赖，也不下载缺失二进制。自动批准只适用于已信任且策略允许的准确调用；程序收录、产物目录与人工保留规则保持独立。数据库迁移到 schema 8，回退前应恢复相应数据库备份。

## English

This consolidated preview brings all local beta.3–beta.5 work to the public release after beta.2.

- ToolHub is now an **extension workbench**: seven optional first-party modules, isolated custom pages/navigation, themes/layouts, explicit install/disable/remove/edit/rollback, and kernel-owned Agent connectivity/permissions/recovery.
- The first **FFmpeg CLI panel** compresses video, converts MP4 and extracts M4A using a selected existing tool, exact argument previews, per-run confirmation and background cancellation. No FFmpeg binary is bundled or downloaded.
- A separate [public extension catalog](https://github.com/xiyuxiao1314/ToolHub-Extensions) and a downloadable examples/SDK bundle make extension selection and development easier.
- The **16 generic MCP tools** stay compact: five summaries by default, with full instance details and Skill instructions loaded only when needed.
- **Selected-project Electron discovery** records actual binaries, versions and project ownership, supports explicit distribution paths, multiple versions and shared-path deduplication, and separates missing/invalid dependencies from available tools. Discovery never executes Electron or elevates trust.
- **Storage maintenance** previews regenerable caches and obsolete packages while protecting active/referenced/current/rollback installations.

Download the native desktop or CLI archive for your OS/architecture and verify `SHA256SUMS.txt`. Keep CLI/daemon/desktop from the same package. Reconnect existing Agent MCP sessions after changing paths. Windows has native execution/media verification; macOS packages are native CI builds with no interactive-parity claim, and controlled execution/approval remains unavailable there. Windows binaries are unsigned; macOS apps are ad-hoc signed and not notarized. Third-party extension scripts never receive unrestricted native authority. Registry schema is now 8; retain a database backup before upgrading/downgrading.
