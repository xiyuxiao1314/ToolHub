# ToolHub v0.3.0-beta.2 — 任务产物与 Agent 执行衔接

[简体中文](#简体中文) · [English](#english)

## 简体中文

这一版让 Agent 创建的临时文件有明确去留，并减少已授权工具执行时的等待。ToolHub 继续整理本机已有工具、应用入口、通用 Skill 与能力包；工具发现保持只读。

### 新功能与修复

- **产物导航**：按任务登记测试脚本、临时输出和备份。文件保留原位置，包记录来源、大小、指纹、理由与清理历史。
- **三个优先级**：低优先级在任务成功完成且明确不再需要后自动回收；中优先级须 Agent 实际核对用途、占用与依赖并提交判断；高优先级及人工保留由用户决定。自动回收都有 5 分钟撤销期。
- **选定范围**：Agent 主动登记，用户选择管理目录后只读扫描历史残留。候选须勾选才收录，默认高优先级；范围外登记可继续任务，但不会自动清理。
- **系统回收站**：重新检查指纹、已知工具/程序/Skill 引用及运行任务；失败保留未处理文件，不提供永久删除兜底。可解除旧登记并保留文件，再选择新版本收录。
- **16 个固定 MCP 工具**：新增产物登记、分页查询/完整清单、完成标记和中优先级判断接口；通用接入 Skill、桌面说明和 TypeScript SDK 同步更新。
- **Windows 自动批准**：设置中默认开启。已信任且策略允许的工具可获得本次准确调用的批准；关闭后继续走审批。未知/已阻止工具、拒绝规则、宿主权限以及程序勾选规则仍然生效。
- **后台与文档**：隐藏 Windows 后台进程控制台，等待实际审批结果；完善中英文说明、新产物页截图，并在安装包内提供英文 README。

### 下载与升级

| 系统 | 桌面包 | CLI / MCP |
|---|---|---|
| Windows x64 | `ToolHub-v0.3.0-beta.2-windows-x64.zip` | `ToolHub-CLI-v0.3.0-beta.2-windows-x64.zip` |
| Mac Apple Silicon | `ToolHub-v0.3.0-beta.2-macos-arm64.dmg` / `.zip` | `ToolHub-CLI-v0.3.0-beta.2-macos-arm64.zip` |
| Mac Intel | `ToolHub-v0.3.0-beta.2-macos-x64.dmg` / `.zip` | `ToolHub-CLI-v0.3.0-beta.2-macos-x64.zip` |

Windows 解压后双击 `toolhub-desktop.exe`，保持配对 CLI、daemon 与资源目录一起。可选安装器 `install-local.ps1` 需要 PowerShell 7，可更新既有登录启动路径。Mac 从 DMG 拖到 Applications，最低 macOS 13。请保留 `~/.toolhub` 用户数据；注册表自动迁移至版本 6。更新 MCP command 到新版 CLI，重载连接和本机接入 Skill。

产物页第一次使用先选择具体任务/项目目录，不默认启用全盘清理。每包最多 128 个普通文件，每个 256 MiB、合计 1 GiB；不回收整个目录。中优先级的判断由接入的 Agent 提交，ToolHub 不内置模型，也不能检测其他应用的一切引用。

Windows 原生回收和桌面流程已在隔离测试中验证。macOS 提供原生构建与测试的预览包，Finder Trash 和文件选择仍需实体 Mac 交互验收；身份绑定的受控工具执行、执行审批和登录自启动暂不可用。Windows 包未做发布者签名；Mac 为 ad-hoc 签名且未公证。校验下载文件请使用 `SHA256SUMS.txt`。

## English

This release adds task artifact lifecycle management and reduces unnecessary waiting for authorized tool execution. Tool discovery remains read-only.

- **Artifacts page:** group explicit temporary files, test scripts and backups by task. Files stay in place; each package records source, fingerprints, reasons and history.
- **Priority rules:** low priority recycles after successful completion and an explicit no-longer-needed declaration; medium adds a real Agent usage/dependency review; high priority and human retention require user decisions. Automatic cleanup has a five-minute cancellation period.
- **Selected scope:** Agents can register their task files; users select management directories and checkbox scan candidates. Historical leftovers default to high priority. Registration outside the scope does not block the Agent or enable cleanup.
- **System Trash:** recheck fingerprints, known references and ToolHub jobs. Failed recycling preserves pending files and has no permanent-delete fallback. Stale registration can be released while preserving the file.
- **16 bounded MCP tools:** four new artifact tools, paginated summaries and full manifests by ID; portable integration Skill and TypeScript declarations updated.
- **Windows automatic approval:** enabled by default for trusted tools allowed by policy and the exact requested invocation. It can be disabled in Settings. Unknown/blocked tools, deny rules, host permissions and program selection requirements still apply.
- **Packaging/docs:** hidden background Windows consoles, bilingual README files in packages, updated release instructions and an Artifacts screenshot.

Use the platform table above to choose Windows x64, macOS Apple Silicon or Intel desktop/CLI packages. Keep paired binaries/resources together and preserve `~/.toolhub`; the registry migrates to schema 6. Update the MCP executable path and reload your connection/integration Skill. Select a specific task/project directory before enabling automatic cleanup.

macOS packages are native CI previews; physical Mac GUI/Finder Trash acceptance remains unverified. Controlled identity-bound tool execution, approvals and login startup on macOS remain unavailable. Windows packages are unsigned; Mac packages use ad-hoc signing without notarization. Verify downloads with `SHA256SUMS.txt`.
