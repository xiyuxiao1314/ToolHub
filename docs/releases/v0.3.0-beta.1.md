# ToolHub v0.3.0-beta.1 — 本机工具与 Agent 能力中心

这是 ToolHub 的首个开源预览发布。ToolHub 把电脑已有的工具、项目启动入口和可复用流程整理给人和 AI Agent 使用，支持本地 stdio MCP，发现工具不依赖 AI 服务。

## 本版内容

- 工具扫描、实用程序识别、按任务搜索、能力解析、默认实例与环境选择。
- 修复大量候选时扫描入库反复读取整表的问题，路径索引一次建立，保留既有候选身份与事务回滚。
- 工具列表按种类或安装实例分页，每页 6 / 12 / 24 项，同一工具的多个版本保留在同一组。
- 程序架：用户先选文件或工作目录，填写名称和参数，后台启动并打开所在目录。Agent 创建的启动入口先提交待确认，用户勾选审核后收录。
- 通用 Skill 库：平台与宿主依赖声明、工具依赖检查，保留宿主专属 Skill 的独立边界。
- 本地能力包市场：8 个内置通用能力包，预览、收录、导入、导出；不自动安装依赖。
- 12 个 MCP 元工具，覆盖发现、解析、检查、执行审批、任务、Skill 和项目应用声明；多宿主模板与历史连接诊断。
- Windows 登录自启动诊断、配对 daemon 管理、只读文件图标提取、受策略约束的执行与活动记录。
- macOS 文件/目录选择与能力包保存入口，工具目录 Terminal 打开，`.sh/.command` 与可执行文件的后台入口支持。

## 下载选择

- Windows x64：`ToolHub-v0.3.0-beta.1-windows-x64.zip`。
- Mac Apple Silicon：`ToolHub-v0.3.0-beta.1-macos-arm64.dmg` 或同名 ZIP。
- Mac Intel：`ToolHub-v0.3.0-beta.1-macos-x64.dmg` 或同名 ZIP。
- CLI / MCP：各平台的 `ToolHub-CLI-v0.3.0-beta.1-<平台>.zip`。
- `SHA256SUMS.txt`：发布资产校验值；源码可以通过 GitHub 自动提供的 Source code 下载。

Windows 解压后双击 `toolhub-desktop.exe`，保持 desktop、daemon、CLI 与资源目录一起。可选的 `install-local.ps1` 需要 PowerShell 7。Mac DMG 中把 ToolHub 拖到 Applications；CLI 位于应用的 `Contents/MacOS/toolhub`。

## 支持情况与限制

Windows 在维护者本机完成构建与原生验证。macOS 提供原生 CI 构建与测试的预览包，尚未在实体 Mac 上完成所有 GUI 交互验收。最低 macOS 13。Windows 需要 WebView2。

macOS 的身份绑定工具执行与执行审批尚未实现，CLI / MCP 会明确返回不可用且不降级到未绑定执行；工具查询和程序架不受此限制。登录自启动、Windows EXE 图标提取、程序的交互“终端启动”和 `.app` 整体启动入口尚未对齐。macOS 项目程序默认扫描用户主目录；工具扫描另包含 Homebrew 等已知位置。Linux、Windows ARM64 和移动端未提供资产。

Windows 包未做发布者签名；Mac 包为 ad-hoc 签名且未公证。请从本 Release 下载并核对校验值，根据系统提示确认来源。CLI-only 包没有桌面审批控制器，不能替代需要用户交互授权的操作。

市场是本地能力包目录，尚无远程社区目录、付费系统或依赖安装。Agent 宿主配置与历史显示不等于执行授权；工具识别也不等于信任。扫描无法仅凭文件证明 AI 作者。

用户数据在 `~/.toolhub`，升级请保留此目录，勿混用不同版本的 CLI、daemon 和桌面。Agent 更新路径后需重载 MCP 连接。
