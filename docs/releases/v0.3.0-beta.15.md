# ToolHub v0.3.0-beta.15 — 应用内更新 / In-app updates

应用内更新的首个引导版本；beta.13 及更早版本请先手动安装本版。

- 设置中新增“软件更新”：检查版本、下载进度、取消下载、安装并重启。
- 启动时自动检查，可关闭；支持稳定版和预览版通道。
- Ed25519 签名和 SHA-256 校验；一次更新桌面、CLI、后台服务和资源。
- 更新期间保护正在执行的任务；保留旧版本，并在启动交接失败时恢复。
- Windows 增加稳定 CLI 接入路径和已配置 ToolHub 连接迁移，减少未来反复改路径。

旧版需要手动安装一次本版；后续可从应用内更新。已连接的 Agent 在更新后需要重新连接 MCP。macOS 实现仍需原生验收，不能以 Windows 验证代替。

English: First bootstrap release for in-app updates. Adds update checks, stable/preview channels, background check preferences, cancellable downloads and explicit install/restart. Updates verify an embedded Ed25519 trust root and SHA-256, replacing the complete paired distribution. Maintenance leases protect in-flight work; startup probation supports recovery before commitment. Windows provides a stable CLI and bounded migration of existing ToolHub connection paths. Older releases need a one-time manual bootstrap; reconnect existing MCP sessions after updating. Native macOS validation is pending.

发布清单与签名在维护者本机生成；私钥不上传仓库或 Actions。本版附 Windows 与 macOS 安装包，macOS 的真实升级/恢复流程仍待实体机验收。

- 修复现存 MCP 会话在更新间隙重拉旧后台的竞态；加入跨进程启动交接锁和当前后台路径选择。
- beta.14 仅有开发标签，正式安装包从 beta.15 提供；首次升级请关闭旧 MCP 会话并重新接入稳定 CLI。
