# ToolHub v0.3.0-beta.3 — Declarative extensions and compact Agent context (unreleased)

This local development version adds a market extension manager for independent JSON tool-recognition rules and portable Skills. Preview/import/install, enable/disable, immutable version updates, one-version rollback and metadata-only uninstall share the daemon registry. A Blender example and developer schema/docs are included. New extension identification does not grant executable trust; existing execution policy still applies.

No executable plugin runtime or online catalog is included. macOS native verification and GitHub publication of this version have not yet been performed. The published v0.3.0-beta.2 release remains unchanged.

MCP search defaults now return five summaries with explicit full/pagination options; native CLI/desktop queries are unchanged. The daily integration Skill uses conditional reference files instead of embedding setup and every advanced workflow. Initialization metadata is shorter. Full execution output, error statuses and authorization checks are retained. Actual billed-token savings depend on the host and model.
