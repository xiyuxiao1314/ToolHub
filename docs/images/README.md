# Screenshot sources / 截图来源

The four PNGs were captured on 2026-10-06 from the native Windows desktop in the published [v0.3.0-beta.1 release](https://github.com/xiyuxiao1314/ToolHub/releases/tag/v0.3.0-beta.1), built from commit `603ce799dd5dad83bf54e6dbc38039c97f05c88d`.

- All images are 1600 × 1000 pixels and show the actual Tauri/WebView2 interface, in Simplified Chinese.
- An independent demonstration registry was used. Tool entries use observed version metadata and copied local binaries under a neutral demonstration directory; project launch entries are examples.
- The Skill and market pages show the real bundled procedures. A dependency was reviewed using the actual trust control in this isolated registry. No program was launched for these captures.
- Private agent configuration, personal project records, credentials, registry databases and demonstration binaries are not included in these documentation assets.
- These are Windows screenshots; they do not constitute macOS GUI acceptance evidence.
