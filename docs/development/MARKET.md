# 通用能力包市场

市场提供内置与用户导入的本地目录。第一版包含 8 个可复用流程：媒体信息检查、视频压缩、图片转换、图片 OCR、PDF 文本与 OCR、文档转换、归档解压、CSV 清洗。

搜索用途、名称、标签或能力 ID，可按分类和必需依赖是否齐备筛选。选择能力包后查看输入输出、平台、权限声明、必需与可选依赖、完整流程和来源信息。已发现但信任未确认、版本不满足等实例会显示需核对原因；不会降低原解析器的候选条件。依赖检查复用 Skill 库的解析器及工具优先级；“依赖齐备”只说明找到了候选工具，不授予执行权限，也不保证任意输入任务成功。

“加入 Skill 库”是明确的收录操作，不会自动安装工具、执行包正文或同步其他 Agent 的专属 Skill。加入后 Agent 可通过现有 MCP `search_skills`、`inspect_skill` 查询。正文可直接复制给 Agent，附带当前依赖结果与重新检查要求。已有同 ID、同内容的 Skill 视为已添加；不同内容拒绝覆盖。

## 导入与分享

通过“导入能力包”的系统文件选择器选择 `.toolhub-skill.json` 或 JSON 文件。选择后仅预览，不写入 Skill 注册表。核对后明确点击加入。预览保留 15 分钟，最多 16 个；到期请重新选文件。复制 JSON 或系统保存对话框可导出分享文件，取消不产生收录或导出。

文件使用 `toolhub.bundle/v1`，格式见 `schemas/skill-bundle.schema.json` 和 `skills/market/` 的示例。包含版本、分类、标签、作者/许可声明、现有 `toolhub.skill/v1` manifest 与 SKILL.md 正文。仅接受明确声明 portable 的 instruction 流程，当前版本不承载脚本、二进制、安装钩子、MCP 配置或宿主 API 依赖。作者与许可是声明，不是身份认证或来源审核。外来正文仍需核对。

上限：整包 128 KiB、正文 64 KiB、必需与可选能力合计 32 项、标签 12 项；运行时按 UTF-8 字节计数并执行语义检查。JSON Schema 的字符上限和语义检查需同时满足。正文发现 Windows 盘符绝对路径或 `/home/`、`/Users/` 路径时阻止分享，避免常见本机路径流出；这不保证发现所有敏感文字，分享前应查看正文。

添加将 manifest、正文与包保存到注册库同目录的 `market/packages/<SHA256>/`，注册 Skill 指向这一稳定快照。默认位于 `%USERPROFILE%\.toolhub\market\packages`。移走原导入文件不影响收录。摘要基于规范化后的内容，重复包去重，资产变更拒绝静默覆盖。加载目录最多展示 64 包，异常包有提示；不支持远程源或在线下载。

## 接口

新增 THP `skill.preview`：参数 `{manifest, instructions, cwd?}`。与 `skill.resolve` 返回同样的兼容性和依赖视图，但只解析传入正文，不注册、不读取声明路径、不授予授权。

`skill.register` 增加可选布尔参数 `if_absent`。为 true 时通过数据库原子插入，仅接受未注册的 ID；冲突返回 InvalidParams 并保留原记录。原有不传参数的注册行为兼容。

桌面原生命令 `market_list/pick/inspect/add/share/export` 仅通过桌面能力开放，复用已验证控制器与本地 IPC。MCP 保持原有 12 个元工具；收录后通过现有 Skill 查询接口访问。

## 后续扩展边界

JSON 包可作为未来远程索引的内容载体。远程来源审核、签名、更新迁移、评分、下载和工具安装不是本次功能；接入时应增加独立的来源与版本治理，不把任意第三方包视为可信执行入口。
