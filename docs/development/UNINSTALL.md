# Uninstall ToolHub (local RC)

1. Stop `toolhubd.exe` / `toolhub-desktop.exe` if running.
2. Delete the install folder containing the three binaries.
3. Optionally delete `%USERPROFILE%\.toolhub\` (registry DB and settings).
4. Remove any Start-menu/shortcut you created.

ToolHub does **not** remove tools it discovered; those are your software.
