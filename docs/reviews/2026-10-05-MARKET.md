# Capability bundle market — 2026-10-05

Owner selected a reusable Skill + local tool requirement catalog. The former market was two navigation buttons. It now offers eight declared portable instruction workflows, purpose/capability search, categories, required-dependency filtering, input/output and instruction preview, explicit Skill-library collection, copy-to-Agent instructions, JSON bundle copy, native import and export dialogs. This is a local built-in/import catalog, with an extensible toolhub.bundle/v1 format; no online community or dependency installation is represented as implemented.

Collection uses stable content-addressed snapshots adjacent to the registry. Same ID + same manifest/body is already collected; differing content rejects replacement. Atomic if_absent insertion prevents a registry race from replacing an existing ID. Dependency preview uses the existing resolver; detected but ineligible instances include trust/version reasons rather than implying no installed tool. Required and optional dependencies remain distinct. Refresh rechecks selected details, eligible provider name/version/path are shown, and the desktop detail pane stays visible while scrolling.

## Limits and extension

Sources/authors/licenses are self-declared. Known host API references and common absolute paths are checked, but arbitrary prose is not proven portable or free of sensitive content. Users review before collection/sharing; no execution permission follows from declarations or collection.

Actual media/document/archive workflows were not executed against user inputs; missing or unconfirmed dependencies are visible. No remote index, download, signatures, rating system, tool installation or cross-host Skill synchronization. Windows delivery was tested; non-Windows native dialogs and real reboot remain unverified.
