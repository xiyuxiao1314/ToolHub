## 项目和 exe 状态

代码包含 Rust 后台服务、CLI、Tauri/React 桌面和自动化测试。当前桌面有工具、智能体、环境、市场、任务、设置六个主页面。

本轮已重新构建三个 Windows 开发版程序：

- `target/debug/toolhub-desktop.exe`：桌面应用。
- `target/debug/toolhubd.exe`：后台服务，桌面会自动启动。
- `target/debug/toolhub.exe`：CLI / MCP 客户端。

桌面和后台 exe 要放在同一目录。项目根目录之外提供 `D:\mimoproject\ToolHub\start-ToolHub.cmd` 作为快捷启动入口。本轮没有生成 MSI / NSIS 安装包或正式 release 构建。
