# Tool brand icon sources

These unchanged assets identify installed tools in ToolHub. Icons extracted from installed executables are preferred; these bundled images cover command-line launchers without an embedded icon and missing files. No runtime network requests are needed.

| `rust.svg` | [rust-lang/rust-artwork](https://raw.githubusercontent.com/rust-lang/rust-artwork/master/logo/rust-logo.svg) | [Official artwork and usage information](https://github.com/rust-lang/rust-artwork) |
